写真台帳アプリ（統合版）ver.2.23　操作マニュアル

株式会社東京航業研究所　調査研究課

現場で撮った写真を、事務所のパソコンで台帳にします。

写真の中の看板を読み取り、看板ごとに写真をまとめ、写真台帳（Excel・CSV）を出力し、ファイル名の付け替えとフォルダ分けまで行います。元の写真は消えません。

このアプリは、これまで別々だった 「写真台帳 照合アプリ（デジタル看板用）」 と 「手書き写し込み台帳アプリ（手書き看板用）」 を1本にまとめたものです。起動時に 2つのモード のどちらかを選んで使います（詳しくは次ページ）。

使う前に

  • パソコン用です。Google Chrome または Microsoft Edge で開いてください。
  • 写真は EOS 6D MarkII などの一眼で撮った JPEG をそのまま使えます。
  • 元の写真は書き換えません。振り分けは「コピーしながら名前を付ける」動作です。
  • 撮影日は看板から読み取った日付を使います。新しいグループを手で作ったときは、直前のグループの日付が初期値になります。

手順1　写真を取り込む

株式会社東京航業研究所　調査研究課

モードを選ぶとこの画面になります。写真の入ったフォルダを選ぶか、フォルダごと画面にドラッグしてください。

  1. 「フォルダを選択」を押す
    写真の入ったフォルダを指定します。フォルダごとドラッグしても構いません。
  2. 読み取りが自動で始まる
    写真を1枚ずつ調べ、看板のQRを探します。パソコンの性能に応じて複数を同時に処理します。
  3. 終わるまで待つ
    進み具合が画面に出ます。8枚で数秒、5000枚だと20分前後かかります。

高精度OCR（クラウド）の設定

取り込み欄の下に 「高精度OCR（クラウド）：中継URL設定」 があります。手書きの読み取りに使いますが、ver.2.1 からは両モードで利用可能で、QRが読めなかった写真の読み取りにも使えます（初回だけ中継サーバーのURLを登録します）。

注意
QRが小さく写っていると読めないことがあります。看板が写真の端に小さく写る場合は、撮影時に看板へ寄るか、被写体に近づけてください。

手順2　QRが読めなかった写真を読み直す（デジタル看板モード）

株式会社東京航業研究所　調査研究課

取り込みが終わったら、まず看板の写真がすべてグループになっているか見てください。QRを読み取れた写真には青い「QR」バッジが付きます。バッジのない看板写真は、ひとつ前のグループに紛れこんだままです。これを拾い上げます。

① 読めなかった看板写真にチェックを入れる

サムネイル左上のチェックボックスで選びます。何枚でもまとめて選べます。選ぶと、画面下に操作バーが出ます。

② 「選択した写真を再スキャン」を押す

通常より強い方法でQRを探し直します。輪郭を強調する処理（OpenCV）と、明暗を整える処理を順に試します。初回は解析の部品を読み込むため数秒待ちます。1枚あたり数秒かかるので、枚数が多いときは時間を見てください。

うまくいくと
読み取れた写真はその場で看板として扱われ、新しいグループが作られます。後ろの写真も自動でそのグループに入り直します。

手順2（続き）　それでも読めないとき／高精度OCRの活用

株式会社東京航業研究所　調査研究課

再スキャンを終えると、何枚読めて何枚読めなかったかが表示されます。光の映り込みが強く、QRそのものが白く飛んでしまった写真は、どう処理しても読めません。

③ 残った写真を選んで「OCRでグループ作成」

QRの代わりに、看板に書かれた文字そのものを読み取ってグループを作ります。件名・調査区分・撮影者・撮影日は、前後のグループから引き継ぎます。作られたグループには紫の「OCR・要確認」バッジが付きます。

高精度OCR（クラウド）を使うと精度が上がりますver.2.1
「高精度OCR（クラウド）」の中継URLを登録してONにしておくと、デジタル看板モードでも 手書きモードと同じ高精度クラウドOCR で読み取ります。未設定・失敗時は端末内OCR（Tesseract）に自動で切り替わります。
注意
OCRは誤読します。必ず「看板を編集」を開き、写真を拡大して現物と見比べてください（手順4）。文字が読めなかった場合も、空のグループだけは作られます。手で入力してください。

どうしても読めない写真は、そのままにしても構いません。ひとつ前のグループに属したまま、台帳にも振り分けにも含まれます。振り分けたくない写真は「失敗にする」を押してください。

手書き看板モードのOCR（看板を手書きOCR）

株式会社東京航業研究所　調査研究課

手書き看板モードでは、看板に貼った 識別QR（内容 "T1"） を「これは看板」という目印として使い、手書きの内容はOCRで読み取ります。

目印として使うQRについてver.2.2
看板の目印として認識するのは、中身が ちょうど「T1」 のQRだけです（同梱の「看板識別QR_印刷シート」で印刷できます）。写真に別のQR（機材の管理QR等）が写り込んでいても、看板と誤認しません。
  1. 中継URLを登録する（初回だけ）
    取り込み欄の「高精度OCR（クラウド）：中継URL設定」に、中継サーバー（Cloudflare Workers など）のURLを入れます。APIキーは中継サーバー側に置くので、ここには入れません。
  2. 「✍ 看板を手書きOCR」を押す
    識別QRで検出したすべての看板を、まとめてクラウドOCRにかけます。中継URLが登録済みなら、取り込み直後に自動で走ることもあります。

実行状況の表示ver.2.1

実行中は 「〇/〇枚完了」 の1行と、下の進捗バーで進み具合が分かります。終わると「完了：〇枚中 〇枚処理・〇件で対象1を読取」とまとまります。

注意
ネットに繋がらない現場では、端末内OCR（Tesseract）に自動で切り替わります（手書き精度は落ちます）。無料枠の上限（レート制限）に達したときは途中で止まります。時間をおいて再度押すと、未読の看板だけ続きから読みます。
ヒント
件名・撮影者・撮影日は、空欄なら直前の看板から自動で前送り補完されます（現場内で一定なことが多いため）。

グループの種類

手順4　看板の内容を直す

株式会社東京航業研究所　調査研究課

グループの「看板を編集」を押すと、左に写真、右に入力欄が並んだ画面が出ます。写真に写っている看板を拡大して確かめながら、右の欄を直せます。

  • ＋／−で拡大縮小。「全体」で全体表示、「1:1」で等倍。右の数字は今の倍率。
  • 写真の上でホイールを回すと拡大。ドラッグで移動。ダブルクリックで全体⇔等倍。
  • 対象1は自由に打ち込めます。遺構種別を選び、下の番号を入れると対象1に自動で入ります（Pは3桁）。
  • 状況・方向・種別などはボタンで選びます。
  • 「保存」で確定。閉じると写真は解放されます。
ヒント
表示されるのは、そのグループの看板写真です。看板写真がない手動グループでは、グループの1枚目が出ます。拡大しても画像は粗くなりません。

撮影日は、看板から読み取れればその日付が入ります。読み取れないときや、手でグループを作ったときは、直前のグループの日付が初期値として入ります。

手順4（続き）　選択肢を追加・削除する

株式会社東京航業研究所　調査研究課

看板を編集する画面では、遺構種別・対象2・状況・種別の選択肢を、その場で追加・削除できます。各項目のラベルの横に「編集」ボタンがあります。

編集できる項目

  • 対象1の遺構種別（P・SI など）
  • 対象2（カマド・炉 など）
  • 状況（検出・完掘 など）
  • 種別（調査・測量 など）

方向は方位盤で固定のため、編集できません。

使い方

  1. 「編集」を押す
    選んだ項目が編集モードになり、各選択肢に赤い×、末尾に追加欄が出ます。
  2. 追加する
    追加欄に文字を入れて「＋追加」または Enter。遺構種別は自動で英大文字になります。
  3. 削除する
    消したい選択肢の赤い×を押します。すでに入力済みの看板情報は変わりません。
  4. 「編集を終了」で戻る
    編集モードを抜けると、また選択できるようになります。
うまくいくと
追加した選択肢はすぐ使えます。編集した内容は「作業を保存」で一緒に保存され、「作業を復元」で戻ります。

手順5　写真台帳を出力する

株式会社東京航業研究所　調査研究課

画面右上のボタンから出力します。写真1枚につき1行、看板の写真も1行として含まれます。

ボタン出力されるもの
台帳Excel出力A列〜M列。撮影日は日付セル（m/d表示）、印刷範囲は実データの行までです。A4横で印刷できます。初回だけ部品をネットから読み込むため通信が必要です。
台帳CSV出力同じ内容をCSVで。既存のExcelマクロに貼り付けられます。オフラインで使えます（現場で通信が無いときはこちら）。数式として実行されないよう自動で無害化します。
作業を保存今の状態を作業状態ファイル（JSON）で保存します。Chrome/Edgeでフォルダを選んで取り込んだ場合は、その写真フォルダの中に「写真台帳_作業状態.json」として保存（毎回上書き）。それ以外の環境ではダウンロード保存になります。
作業を復元Chrome/Edgeでは写真フォルダを選ぶだけで、フォルダ内の作業状態ファイルを読み込み、写真を取り込み、保存時に未処理だった（新しく増えた）写真だけを自動で解析して続きから再開します。それ以外の環境ではJSONファイルを選ぶ方式です。
「種別2」の既定ver.2.1
台帳の「種別2」（J列）は、対象写真の行で空欄のとき、自動で 「調査」 が入ります。看板そのもの（写込）の行は、これまでどおり種別1＝写込・種別2＝空のままです。
「作業を保存／復元」の写真の対応づけver.2.2
作業状態は、ファイル名だけでなく サブフォルダを含む相対パス で写真を対応づけて保存・復元します。別のサブフォルダに同名ファイルがあっても取り違えません。ver.2.1以前に保存したJSONも読めますが、その場合は同名写真が1枚だけのときに限り復元します（一度 ver.2.2 で保存し直すと以後は確実になります）。
フォルダに保存 ＆ フォルダから再開ver.2.21
Chrome / Edge でフォルダを選択（またはフォルダごとドラッグ＆ドロップ）して取り込んだ場合、「作業を保存」でその写真フォルダの中に作業状態ファイルが保存されます（ダウンロードフォルダを探す必要がありません）。次回は 「作業を復元」でそのフォルダを選ぶだけで、保存した状態を戻し、さらに撮り足した写真だけを自動で解析して続きから作業できます。フォルダをドラッグ＆ドロップした場合も、保存済みの状態があれば取り込み時に「復元しますか？」と確認します。※個別ファイルのドロップや「複数ファイル選択」ではフォルダに保存できず、ダウンロードになります。

あとから写真を足したとき

撮り足した写真を同じフォルダに入れて、もう一度取り込んでください。すでに読み取り済みの写真は飛ばし、新しい写真だけを解析します。新しいグループには緑の「追加」バッジが付き、「追加された写真のグループだけ表示」で絞り込めます。

振り分けたくない写真

ピンぼけや試し撮りなど、振り分けたくない写真は、サムネイルの「失敗にする」を押してください。台帳には残りますが、写真のコピーからは外れます。

手順6　写真を振り分ける

株式会社東京航業研究所　調査研究課

台帳の内容にしたがって、写真をコピーしながら名前を付け替え、フォルダに分けます。Excelマクロの「写真振り分け」と同じ動作です。元の写真はそのまま残ります。

  1. コピー元フォルダを指定
    取り込んだときのフォルダが自動で入ります。違うときだけ選び直します。
  2. 保存先フォルダを選ぶ
    新しい空のフォルダを推奨します。
  3. プレビューを作って実行
    どの写真がどこへ行くか、一覧で確認してから実行します。

付けられる名前

〔対象1〕 〔対象2〕 〔状況〕（〔方向〕）_〔種別〕_〔元のファイル名〕.JPG

例：SI13 カマド 完掘（南西）_調査_IMG_5624.JPG

入れられるフォルダ

条件フォルダ
種別が 調査・測量・メモ・空欄調査区分 ／ 対象1　（例：本調査／SI13）
それ以外の種別調査区分 ／ 種別　（例：本調査／管理）

ファイル名やフォルダ名に使えない文字（\ / : * ? " < > | [ ]）は自動で取り除かれます。

処理が遅い画面上部で同時処理の数を変えられます。24コアのパソコンなら8並列が目安です。
OpenCV・OCRが動かない会社のネットワークが外部を遮断していることがあります。opencv.js と Tesseract 一式を、index.html と同じフォルダに置いてください。ローカルのファイルが優先されます。
解析を途中で中断したver.2.2では、中断すると未解析の写真は台帳へ反映されません（誤った台帳化を防ぐため）。もう一度取り込み直してください。
作業を中断したい「作業を保存」でJSONを保存し、次回「作業を復元」で続きから始められます。古いバージョンで保存したJSONも読めます。

覚えておくとよいこと

  • 看板の写真も台帳の1行に含まれます。マクロと同じ動作です。
  • 並び順は撮影日時ではなく、ファイル名の順です。
  • 看板に入力した「種別」が、フォルダ分けを決めます。「写込」は無視されます。
  • 台帳の「種別2」は、対象写真の行で空欄なら既定で「調査」が入ります（ver.2.1）。
  • 高精度クラウドOCRは、デジタル看板モードでも手書き看板モードでも使えます（ver.2.1）。
  • 手書きモードで看板の目印になるQRは、中身が「T1」のものだけです（ver.2.2）。
  • 作業の保存／復元は、サブフォルダを含む相対パスで写真を対応づけます（ver.2.2）。
  • 項目に半角の「|」を打つと、QRでは全角の「／」に変わります。「第1次／第2次」のように全角で打つぶんには問題ありません。
