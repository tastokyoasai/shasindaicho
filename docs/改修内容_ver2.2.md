# 写真台帳アプリ 統合版 ver.2.2 改修内容

ver.2.1の静的レビューで見つかったデータ整合性・安全性・出力上の問題を修正した版です。基本操作は同梱のver.2.1操作マニュアルと同じです。

## 主な修正

- サブフォルダの区切りを保持してコピー元写真を探索
- 作業状態JSONで写真を「相対パス＋ファイル名」により識別
- 旧版JSONは同名写真が1枚だけの場合に限り互換復元
- 解析中断時、未解析写真を台帳へ混在させない
- 写込指定を、JSONを読み込む順序にかかわらず復元
- マスタ・撮影者の選択肢をDOM APIで生成し、HTML属性への文字列埋込みを廃止
- CSVの数式注入対策
- Excel撮影日を日付セルとして出力し、印刷範囲を実データ行までに変更
- `file://`でも同梱Tesseractを先に読み込む方式へ変更
- 手書きモードの識別QRを `T1` に限定
- 未実装だった「看板アプリのJSONを併用」項目を画面から削除

## Cloudflare Worker

- `ALLOW_ORIGIN`を必須化
- JPEG以外を拒否
- リクエスト全体10MB、Base64文字列8MB、復号後画像6MBを上限化
- Rate Limiting bindingを追加（60回/分）
- OCR候補値を許可リストで検査

デプロイ前に次を実行してください。

```powershell
npx wrangler secret put GEMINI_API_KEY
npx wrangler secret put ALLOW_ORIGIN
npx wrangler deploy
```

`ALLOW_ORIGIN`には `https://ユーザー名.github.io` のようなオリジンを入力します。末尾のスラッシュやリポジトリ名のパスは含めません。

## 互換性

- ver.2.1の作業状態JSONは読み込めます。
- ただし旧JSONは相対パスを持たないため、異なるサブフォルダに同名写真がある場合、その写真は安全のため自動復元しません。
- ver.2.2で保存し直すと、以後は同名写真を相対パスで区別できます。
- Excel出力はExcelJSをCDNから読み込むため、初回実行時にネット接続が必要です。CSV出力はオフラインで利用できます。
