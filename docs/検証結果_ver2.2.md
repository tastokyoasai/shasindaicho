# ver.2.2 検証結果

## 実施済み

- `index.html` 内の全script要素をJavaScriptとして構文検査
- `worker.js` をES Moduleとして構文検査
- `wrangler.toml` をTOMLとして解析し、Rate Limiting設定を確認
- 相対写真キー：`ROOT/sub1/sub2/IMG_0001.JPG` → `sub1/sub2/IMG_0001.JPG`
- サブフォルダ分解：`sub1/sub2` → `sub1`, `sub2`
- Excel日付：正常日をDate化し、不正日を拒否
- Workerプリフライト：許可オリジンへCORSヘッダーを返す
- Worker不許可オリジン：403
- Worker不正MIME：415
- Workerレート超過：429
- Workerリクエスト10MB超過：413
- 主要回帰項目11件の静的確認
